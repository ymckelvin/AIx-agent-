# Export Contract

## 必须交付

- PNG：按指定尺寸导出。
- Source：HTML/CSS/React 或 Figma-ready 源文件。
- Design System Contract：本次项目冻结的设计系统。
- Review Report：独立评审结果。
- Checklist：上线前检查清单。

## 尺寸校验

所有导出文件必须进行像素级校验：

```text
expected_width == actual_width
expected_height == actual_height
```

## 字体要求

最终交付的文字必须由真实字体渲染，不接受不可编辑的 AI 假字。

## 资产要求

Logo 和主视觉符号必须使用源资产引用，不允许重新生成。
