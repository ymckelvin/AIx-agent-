# Review Contract

## 问题等级

| 等级 | 含义 | 处理 |
|---|---|---|
| P0 | 上线事故 / 必须打回 | 必改，不允许交付 |
| P1 | 影响效果 / 品牌一致性风险 | 原则上修改 |
| P2 | 审美 polish / 可优化 | 记录建议，视情况修改 |
| P3 | 备注 | 不阻塞 |

## P0 硬性打回项

- 尺寸不准确。
- Logo 被重绘、改色、拉伸、错位。
- 主视觉符号被重绘或改形。
- 核心文案错字、漏字、乱码。
- 字体明显漂移或使用禁用字体。
- CTA 不清楚或不可点击感弱。
- 违反用户明确禁用项。
- 最终上线物料中文字不是真实字体渲染。

## 评分卡

| 模块 | 权重 |
|---|---:|
| 业务传达 | 25 |
| 信息层级 | 20 |
| 品牌一致性 | 20 |
| 视觉质量 | 20 |
| 可交付性 | 15 |

上线门槛：90+ 可上线；80-89 需修 P1；70-79 方向可用但需重做；低于 70 不建议上线。
